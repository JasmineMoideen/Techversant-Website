AI-Driven Proctoring Solution for Seamless Integration with EDTech Partners

Project Summary

Techversant Infotech Pvt Ltd partnered with a tech integration firm to develop and integrate an AI-powered proctoring tool for a learning management system provider in the safety training domain. The goal was to create a secure, scalable solution that ensures exam integrity without relying on third-party software. Built with JavaScript, Python, React/Node, and AI/ML modules the tool verifies identities, monitors behavior, and flags violations in real-time, all while integrating smoothly with the LMS platform.

The Challenges

The integration partner needed a proctoring solution to enhance their clients’ training programs. Many clients, particularly in industries like construction and energy, required secure online exams to certify workers. Manual proctoring or external tools were costly, inconsistent, and hard to integrate with existing systems. Clients needed a way to verify candidate identities, enforce exam rules (e.g., no external devices or resources), and generate reliable reports—all within their current workflows. The solution had to be modular for future integrations and cost-effective to deploy.

The Collaboration

Techversant delivered a tailored proctoring tool, leveraging AI to meet these needs. The system comprises four components:

  • JavaScript Application: A lightweight frontend snippet embedded in BISTrainer, enabling students to access exams without downloads. It handles permissions (webcam, mic, screen-sharing) and connects to backend APIs.
  • React:  Powers the admin panel
  • Node Application: Manages backend logic, stores data, and supports manual verification. It processes inputs, generates reports, and uses WebSockets for efficient data transfer.
  • Python Application: Serves as a bridge between the frontend and AI modules.
  • AI/ML Application: Drives identity verification and behavior monitoring. It uses facial recognition to match IDs with webcam images, detects violations (e.g., multiple faces, external devices), and refines accuracy through continuous training.

The tool supports four proctoring levels, from basic ID checks (Level 1) to strict monitoring (Level 4), including screen tracking and multi-monitor restrictions. The integration partner customized APIs to sync data with the Client’s course management system, ensuring admins could assign proctoring levels, review reports, and override flags directly in the platform. Media files (e.g., screenshots) are stored in AWS S3 for agreed duration, and violation details are logged in DynamoDB for audits.

The Results & Business Impact

The AI-powered proctoring tool was piloted with a safety training provider, proctoring 500 exams within the LMS platform. The integration showcased its ability to enhance workflows, improve compliance, and adapt to real-world needs. Here’s what the collaboration achieved:

  • Facial Recognition: Processed 500 exams with seamless ID verification using facial recognition, ensuring accurate candidate authentication.
  • Reduced exam oversight time: Allowing admins to monitor and review sessions efficiently through the LMS.
  • Flagged violations (e.g., leaving camera view, using unauthorized devices) with timestamps and screenshots, minimizing manual checks.
  • Enabled quick integration in under two weeks, leveraging modular APIs for a smooth fit into the existing platform.
  • Triggered email re-verification links for identity mismatches, streamlining compliance without disrupting users.
  • Cut certification delays by providing real-time streams and reports, boosting client satisfaction and trust.
  • Extended functionality to other platforms, adapting outputs for diverse training systems with minimal adjustments.
